KOPKOMPETENSI KEAHLIAN

Tentang TJKT

Mengenal lebih dekat jurusan Teknik Jaringan Komputer dan Telekomunikasi.

Teknik Jaringan Komputer & Telekomunikasi

TJKT adalah jurusan yang mempelajari cara instalasi jaringan komputer, perbaikan perangkat keras/lunak komputer, administrasi server jaringan, sistem telekomunikasi berbasis kabel maupun nirkabel, serta keamanan siber.

Server Administration

Mengelola sistem operasi server jaringan baik lokal maupun berbasis cloud.

Routing & Switching

Konfigurasi perangkat router dan switch untuk konektivitas jaringan skala luas.

Telekomunikasi

Mempelajari transmisi data nirkabel, fiber optic, dan teknologi jaringan masa kini.

Network Security

Melindungi infrastruktur jaringan dari ancaman siber dan penyusupan.
